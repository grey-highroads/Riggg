# The Assembly Press — Usage Rules

## Visual Identity

**Accent glow color:** `accent-purple` (#9C27B0)
**Machine silhouette:** Wide horizontal machine with multiple processing stations — a stamping press, a cutting mechanism, a folding station — all feeding into sorted output bins. The widest and most complex machine in the factory.
**Signature detail:** Multiple distinct output types visible simultaneously — film reel spools, titled cards, framed thumbnail prints, bundled guest kits — showing the variety of assets produced from a single input.

## Machine-Specific Elements

- Multi-stage processing stations visible (stamp, cut, fold, finish)
- Purple glow in the central processing chamber where raw source material transforms
- Multiple output bins/trays, each containing a different asset type
- Small film reel spools (clips) stacked or hanging from brass hooks
- Title cards with visible text-like markings (no readable text — just impression of formatted content)
- Thumbnail frames in a drying rack or print stack
- Guest kit bundles wrapped with brass clasps
- Brass label maker or stamping die for titles
- Most output-dense machine — should visibly produce more types of things than any other

## Do / Don't

### Do
- Show multiple distinct output types — this machine's defining trait is variety and volume
- Include the stamping/pressing action — titles and formatting are acts of craft
- Show the transformation from raw input to finished assets (before/after visible)

### Don't
- Show only one output type — Package makes many things from one session
- Make it look like a simple conveyor — the multi-station complexity is the point
- Include distribution/channel elements (those belong to Publish)
