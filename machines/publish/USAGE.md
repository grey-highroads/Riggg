# The Distribution Engine — Usage Rules

## Visual Identity

**Accent glow color:** `accent-blue` (#2196F3)
**Machine silhouette:** Central intake chamber with blue glow, fanning out into 5-7 labeled output chutes/channels, each with a small indicator light. Emphasizes the one-to-many routing action.
**Signature detail:** Labeled channel destination slots — small brass plates reading channel indicators (no readable text, but impression of labeled destinations). Each chute has its own small indicator light.

## Machine-Specific Elements

- Central sorting mechanism with brass routing arms
- Blue glow in the intake/processing chamber
- 5-7 labeled output chutes fanning outward (the "channel" destinations)
- Small indicator lights at each chute (some green/active, showing successful delivery)
- Manifest clipboard or routing schedule hung on the side
- Conveyor belt splits into branching tracks on the output side
- Small stamps or address-like markings on outgoing content cards
- The machine that most visibly "sends things out" — directionality matters

## Do / Don't

### Do
- Show the one-to-many routing action — one input, multiple destinations
- Include labeled output chutes — the channel system is the defining feature
- Show indicator lights — successful distribution should feel visible and confirmed

### Don't
- Show content creation or transformation — Publish distributes, it doesn't create
- Show only one output channel — the multi-channel routing is the point
- Confuse with Package outputs — Publish routes finished assets, not raw material
